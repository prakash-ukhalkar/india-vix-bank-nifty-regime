Response to Reviewers
Manuscript ID: NCAA-D-26-02775R1
Title: India VIX Regime-Conditional Directional Prediction of Bank Nifty: A Stacking Ensemble Approach
Journal: Neural Computing and Applications
Dear Editor and Reviewers,
We sincerely thank the Editor and all Reviewers for the detailed and constructive feedback. We have substantially revised the analysis pipeline and manuscript to address concerns on leakage, look-ahead bias, overlapping outcomes, regime concentration, baseline benchmarking, trading-protocol clarity, and reporting transparency. Where corrected analyses did not support our earlier claims, we have revised the manuscript narrative conservatively and explicitly. Below we provide a point-by-point response.
---------------------------------------------------------------------------------------------------------------------
Reviewer 1
R1.1 Threshold look-ahead bias
Reviewer comment: The High-VIX threshold was previously estimated from the test-period distribution, constituting look-ahead bias.
Response: Accepted. The original threshold (15.08) was computed from the test-period VIX distribution, which is unavailable in real deployment. We recalibrated the primary regime threshold using only pre-test data (train + validation periods).
Changes made: 
Primary threshold set to the 75th percentile of the train+validation VIX distribution: 18.71 (replacing the biased 15.08).
Under the corrected fixed threshold, the High-VIX test subset contains 8 observations (was 58 under the biased threshold); Low-VIX contains 248 (was 219).
Regime partition for all downstream analyses recomputed under the fixed pre-test threshold.
Expanding-window and rolling-252-day p75 threshold comparisons are also reported for sensitivity; both yield similar counts (8 and 52, respectively).
Location in revised manuscript: Section 3.4 (regime definition and threshold calibration), Section 6.3 (threshold sensitivity), and Table 11 (threshold-comparison summary).
R1.2 Overlap dependence in inference
Reviewer comment: The 21-day horizon induces overlapping outcomes and serial dependence, invalidating i.i.d. inference.
Response: Accepted. We replaced i.i.d.-style Fisher test with dependence-aware procedures throughout.
Changes made: 
Non-overlapping Fisher exact test: every 21st aligned observation is used (approximately 12 non-overlapping pairs from 256 aligned rows).
Circular block-bootstrap confidence interval (block length = 21): 95% CI for the accuracy difference = [16.2 pp, 51.4 pp].
Block-permutation test: p = 0.357 (before Bonferroni); p = 1.000 after Bonferroni correction across 3 horizons. The result is not significant at the corrected level.
Manuscript narrative revised to emphasise sparse support (n = 8) and the distinction between observational pattern and statistically certified predictability.
Location in revised manuscript: Section 6.3 (dependence-aware inference and uncertainty analysis), Table 5 (statistical tests), and Fig. 9 (bootstrap confidence intervals and temporal concentration).
R1.3 Generalizability from a single stress episode
Reviewer comment: High-VIX observations concentrated in one episode may make findings event-specific and not generalizable.
Response: Accepted. We added walk-forward yearly evaluation and tempered all generalizability claims accordingly.
Changes made: 
Year-wise walk-forward analysis (2019–2025): in each year's held-out window the High-VIX accuracy advantage is inconsistent (positive in 2021, negative in 2019, 2020, 2022, 2024, and 2025), confirming episode-specific concentration of the result.
The manuscript now explicitly states that the 21-day High-VIX result should not be extrapolated beyond the evaluated test period without additional replication.
Location in revised manuscript: Section 6.4 (walk-forward generalizability analysis), corresponding walk-forward results table, and Fig. 10.
R1.4 Sharpe claim inconsistency at 50 bps
Reviewer comment: The text previously overstated Sharpe superiority of the strategy versus buy-and-hold even at 50 bps transaction cost.
Response: Accepted and fully corrected. The prior claim was an artefact of an overlapping-position simulation with incorrect cost conversion. We rebuilt the simulation under a non-overlapping, deployable protocol.
Changes made: 
Corrected buy-and-hold Sharpe: 1.204 (was 1.963 under old protocol).
Corrected High-VIX + Up strategy (1 trade, 21 active days / 256 evaluation days):
TC = 0 bps:  cumulative return +9.91%,  Sharpe 0.455  (vs BH 1.204)
TC = 10 bps: cumulative return +9.80%,  Sharpe 0.439
TC = 20 bps: cumulative return +9.69%,  Sharpe 0.423
TC = 30 bps: cumulative return +9.58%,  Sharpe 0.407
TC = 50 bps: cumulative return +9.36%,  Sharpe 0.375  (vs BH 1.204)
The strategy does not exceed buy-and-hold Sharpe at any tested cost level. Maximum drawdown is lower (−3.69% vs −6.62%). The abstract, conclusion, and all tables have been updated to reflect corrected values.
Location in revised manuscript: Section 5.3 (trading interpretation, signal timing, and execution protocol), Table 8 (trading performance), Table 9 (cost sensitivity), and Fig. 5 (equity curves).
R1.5 Signal timing and execution ambiguity
Reviewer comment: Potential look-ahead due to unclear signal and execution timing.
Response: Accepted. We define and implement a fully deployable timing protocol.
Changes made: 
Signal computed from all features available after market close on day t.
Entry at open price on day t+1.
Exit at close price on day t+21.
At most one concurrent position; no pyramiding or overlapping trades.
Location in revised manuscript: Section 5.3 (signal timing, execution protocol, and trading-evaluation assumptions).
R1.6 Regime-local baseline and class metrics
Reviewer comment: Need within-regime majority baseline, precision, recall, and F1.
Response: Accepted. Regime-local baselines and class-stratified metrics are now reported and interpreted conservatively.
Changes made: 
High-VIX (n = 8): all 8 days directionally Up; majority baseline = 100%; model accuracy = 100%, precision = 100%, recall = 100%, F1 = 100%. The model matches the local majority — no additional edge is claimed.
Low-VIX (n = 248): majority Up rate = 70.2%; majority baseline = 70.2%; model accuracy = 66.5%, precision = 69.4%, recall = 93.7%, F1 = 79.7%, AUC = 0.584. The model is below the majority baseline at the unconditional level.
Overall (n = 256): model accuracy 67.6%, majority baseline 71.1%. McNemar p = 0.022 (corrected, two-sided).
Location in revised manuscript: Section 5.2 (regime-conditioned accuracy), Table 7 (regime-stratified metrics), and Table 4 (regime diagnostic statistics).

R2.4 Sharpe calculation conventions not stated

Sharpe ratio: annualized as (mean daily return / std daily return) × √252.
